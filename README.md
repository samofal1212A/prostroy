# GavrilovBud — оренда будівельного риштування

Адаптивний односторінковий сайт для компанії з оренди будівельного риштування у Львові та області.

## Про проєкт

Мета проєкту — створити сучасний комерційний сайт, який презентує послуги компанії, допомагає клієнту ознайомитися з видами риштування та залишити заявку на розрахунок вартості.

## Реалізовано

- адаптивний дизайн для desktop, tablet та mobile;
- семантична HTML5-структура;
- навігація між секціями сайту;
- головний екран із закликами до дії;
- каталог видів будівельного риштування;
- блок переваг компанії;
- секція «Як це працює?»;
- блок «Про компанію»;
- форма розрахунку вартості;
- секція контактів;
- адаптивний footer;
- hover-ефекти та CSS-анімації.

## Особливості

Проєкт розроблений з орієнтацією на комерційний сценарій. Користувач може швидко ознайомитися з послугами, переглянути види риштування та перейти до форми розрахунку вартості.

Особливу увагу приділено адаптивній верстці, структурі контенту, навігації та зручному розташуванню CTA-елементів.
